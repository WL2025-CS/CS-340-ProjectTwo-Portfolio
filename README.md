CS-340 Grazioso Salvare Dashboard
Tools: Python, MongoDB, Dash, Plotly, Pandas
How I write maintainable code: I built the CRUD module as a reusable class so the dashboard could call database functions without knowing MongoDB details. It can be reused in future projects.
My problem-solving approach: I broke the project into layers - database, CRUD module, then dashboard - integrating all three into one working system for a real client.
Why it matters: The dashboard lets Grazioso Salvare filter thousands of animal records to quickly find rescue dog candidates, saving staff time.
